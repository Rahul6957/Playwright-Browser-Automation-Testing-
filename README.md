# Online Book Shop (BookHub)

An online book shopping application that allows users to browse books, register, log in, add books to the cart, place orders, and view bills.

## Automation Testing – Playwright

A separate automation testing folder is maintained to learn and practice browser automation using Playwright.

### Testing Goals

* Automate login and registration testing.
* Test book listing functionality.
* Test add-to-cart functionality.
* Test checkout and order flow.
* Validate application behavior using automated test cases.

### Technologies

* Backend: Node.js, Express.js
* Database: MySQL
* Automation Testing: Playwright
